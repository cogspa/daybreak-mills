# assets/brand

Drop brand imagery here and pick this folder in the studio's **Brand assets**
box. Files are matched to slots by name, extension ignored:

    logo.png           the wordmark — goes on every bone chip (front + top flap)
    character.png      the mascot — front panel bottom-left, and large on the back
    bowl_golden.png    product shot for Golden Flakes
    bowl_cocoa.png     … Cocoa Comets
    bowl_berry.png     … Wildberry Loops
    bowl_honey.png     … Honey Clusters
    bowl_frosted.png   … Frosted Stars
    bowl_bran.png      … Sprouted Bran
    bowl.png           generic fallback for any flavour without its own

The brief picks the bowl for whichever flavour it recommends, so one folder
covers the whole range. Transparent PNGs work best — the field colour shows
through. `wordmark`, `mascot`, and `product_<flavour>` are accepted aliases.

The four files here are placeholders generated for testing. Replace them.

**Save asset pack** in the studio writes everything as one JSON so a set can be
reloaded in one click without re-picking the folder.
